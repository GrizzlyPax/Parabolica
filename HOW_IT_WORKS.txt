================================================================================
                           WHAT IS THIS?
================================================================================

This is a racing simulation engine inspired by Blaseball. It generates:

  - Random drivers with weird names (like "Pancake Thunderpants")
  - Teams with emoji avatars
  - Tracks with unique properties, layouts, and weather
  - Chaos cards that modify races in fun ways
  - Season-long leagues with points and standings
  - F1-style tire strategy with pit stops and compound variety
  - Crashes, pileups, and tire blowouts for drama

The goal is to create entertaining, unpredictable races where you can see
exactly WHY things are happening via the Analytics tab.

================================================================================
                     THE BIG PICTURE: HOW A RACE WORKS
================================================================================

Every 100 milliseconds (configurable), the simulation "ticks". On each tick:

  1. EACH DRIVER gets a speed calculation:

     FINAL SPEED = Base Roll × Stats × Consistency × Luck × Endurance × Chaos × Tires

  2. Tire wear accumulates based on driving style and compound
  3. Crash proximity checks occur when drivers are close together
  4. Pit stop decisions are evaluated (mandatory 2 stops, must use all compounds)
  5. The driver's position advances along the track
  6. When the leader finishes, all drivers complete their current lap
  7. Race ends when all drivers finish or DNF

================================================================================
                         TIRE SYSTEM (NEW!)
================================================================================

The tire system adds real strategy to races. Drivers must make 2 pit stops
and use all 3 tire compounds during a race.

TIRE COMPOUNDS:
┌────────────┬───────────┬───────────┬────────────┬───────────────────────────┐
│ COMPOUND   │ SPEED     │ WEAR RATE │ CLIFF AT   │ BEHAVIOR                  │
├────────────┼───────────┼───────────┼────────────┼───────────────────────────┤
│ SOFT       │ +8% bonus │ 1.5x      │ 70% wear   │ Sharp cliff, high blowout │
│ (Red)      │           │           │            │ risk. Sprint tire.        │
├────────────┼───────────┼───────────┼────────────┼───────────────────────────┤
│ MEDIUM     │ Baseline  │ 1.0x      │ 80% wear   │ Moderate cliff. Balanced. │
│ (Yellow)   │           │           │            │                           │
├────────────┼───────────┼───────────┼────────────┼───────────────────────────┤
│ HARD       │ -5%       │ 0.7x      │ 88% wear   │ Gentle cliff. Durable.    │
│ (White)    │           │           │            │                           │
└────────────┴───────────┴───────────┴────────────┴───────────────────────────┘

DEGRADATION CURVE:
  - 0-40% wear: Full compound performance
  - 40% to critical: Gradual 5% performance loss
  - Past critical: THE CLIFF - compound-specific steep drop
    • Soft: Loses up to 32% speed rapidly
    • Medium: Loses up to 20% speed
    • Hard: Loses up to 12% speed
  - Floor at 60% performance (can't go lower)

TIRE BLOWOUTS:
  - Risk only exists past critical wear threshold
  - Chance scales exponentially as wear approaches 100%
  - Soft tires have highest blowout risk (0.4% base, up to 2% at max wear)
  - Aggressive (low consistency) drivers have 30% higher risk
  - Blowout = instant DNF with dramatic event message

PIT STRATEGY:
  - Mandatory 2 pit stops per race
  - Must use all 3 compounds during the race
  - AI calculates optimal pit windows based on tire wear
  - Pit stop takes ~40 ticks (4 seconds)
  - Entering/exiting pit lane shown on track visualization

================================================================================
                         SPEED CALCULATION BREAKDOWN
================================================================================

Here's exactly what happens when we calculate a driver's speed each tick:

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: BASE ROLL                                                           │
│                                                                             │
│ We roll a random number between 0 and 1, then scale it:                    │
│                                                                             │
│   Base Speed = Min Speed + (Roll × (Max Speed - Min Speed))                │
│                                                                             │
│ Default: Min=5, Max=20, so base speed is 5-20 units per tick               │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: DRIVER STATS MODIFIER                                               │
│                                                                             │
│ Each driver has a "baseSpeed" stat (0.85 - 1.15)                           │
│                                                                             │
│ A driver with baseSpeed=1.15 is 15% faster than average                    │
│ A driver with baseSpeed=0.85 is 15% slower than average                    │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: CONSISTENCY EFFECT                                                  │
│                                                                             │
│ High consistency = your speed stays close to average (less risky)          │
│ Low consistency = wild swings (could be amazing or terrible)               │
│                                                                             │
│ The math: We look at how far the base roll was from average, then          │
│ reduce/amplify that variance based on consistency stat.                    │
│                                                                             │
│ Consistency=0.8: Reliable, performs close to expected                      │
│ Consistency=0.3: Wildcard! Could be great, could be awful                  │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: LUCK BONUS (Time-based proc)                                        │
│                                                                             │
│ Every tick, there's a 3% chance of a luck proc for ALL drivers.            │
│ The driver's luck stat affects MAGNITUDE, not frequency:                   │
│                                                                             │
│   If triggered: Boost = 1 + (Luck stat × 0.3)                             │
│   A high-luck driver gets up to +30% speed boost                          │
│   A low-luck driver gets only +9% speed boost                             │
│                                                                             │
│ This means everyone has equal CHANCE at luck, but lucky drivers            │
│ benefit more when it procs.                                                │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: ENDURANCE FACTOR                                                    │
│                                                                             │
│ Drivers get tired over the race. Each lap:                                 │
│                                                                             │
│   Effective Endurance = Base Endurance - (Lap Number × Decay Rate)         │
│                                                                             │
│ High endurance drivers barely slow down over laps                          │
│ Low endurance drivers fade badly in later laps                             │
│                                                                             │
│ Minimum endurance factor is capped at 0.5 (you never stop completely)      │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 6: CHAOS MODIFIER (Random Events)                                      │
│                                                                             │
│ If random events are enabled (default: yes), each tick has a small         │
│ chance of triggering a chaos event:                                        │
│                                                                             │
│   50% chance: SLOWDOWN (multiply speed by 0.7-1.0)                         │
│   50% chance: BOOST (multiply speed by 1.0-1.25)                           │
│                                                                             │
│ The Chaos Level setting controls how extreme these effects are.            │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 7: TIRE MODIFIER                                                       │
│                                                                             │
│ Final speed is multiplied by tire performance:                             │
│                                                                             │
│   Fresh soft tires: ×1.08 (8% bonus!)                                     │
│   Fresh hard tires: ×0.95 (5% slower but longer lasting)                  │
│   Worn tires past cliff: ×0.60-0.80 (major penalty!)                      │
│                                                                             │
│ Tire modifier is tracked separately in analytics so you can see            │
│ exactly how much strategy affected each driver.                            │
└─────────────────────────────────────────────────────────────────────────────┘

================================================================================
                         CRASH & DNF SYSTEM
================================================================================

CRASH PROXIMITY:
  - When drivers are within 3% of track position, crash risk activates
  - Base crash chance: 0.08% per tick (reduced for longer races)
  - More drivers close together = higher pileup risk
  - Crashes can involve multiple drivers

CRASH OUTCOMES:
  - 70% chance: DNF (out of the race entirely)
  - 30% chance: Damaged but continue with 15% speed penalty

TIRE FAILURES:
  - Only occur past critical wear threshold
  - Probability increases exponentially near 100% wear
  - Aggressive drivers are more prone to blowouts
  - Always results in DNF

================================================================================
                          RACE FINISH LOGIC
================================================================================

The race uses F1-style finish logic:

  1. When the LEADER crosses the finish line, the race enters "final lap" mode
  2. All other drivers complete their CURRENT lap, then are classified
  3. Drivers on the lead lap are ranked by finish time
  4. Lapped drivers are classified after all lead-lap drivers
  5. DNF drivers are classified by when they retired

This prevents lapped cars from being incorrectly placed on the podium.

  - Shows when drivers gained/lost positions

FACTOR BARS:

    • Chaos boosts/penalties (blue/pink bars)
    • Endurance impact (green bar)

EVENT TIMELINE:
  - Chronological feed of significant race events
  - Crashes, lead changes, pit stops, tire warnings, etc.
  - Filter by event type or significance

================================================================================
                            DRIVER STATS EXPLAINED
================================================================================

Each driver has 5 stats that define their racing style:

┌────────────────┬─────────────────────────────────────────────────────────────┐
│ STAT           │ WHAT IT DOES                                                │
├────────────────┼─────────────────────────────────────────────────────────────┤
│ Base Speed     │ Raw speed multiplier. 1.0 = average. Higher = faster.      │
│ (0.85 - 1.15)  │ The most straightforward stat.                              │
├────────────────┼─────────────────────────────────────────────────────────────┤
│ Consistency    │ How reliable they are. 0.8 = very consistent.              │
│ (0.3 - 0.8)    │ 0.3 = completely unpredictable (could be genius or trash). │
│                │ Also affects tire wear (aggressive = more wear).           │
├────────────────┼─────────────────────────────────────────────────────────────┤
│ Luck           │ Magnitude of luck boosts when they proc. Higher = luckier. │
│ (0.3 - 0.8)    │ A lucky driver can upset the favorites!                    │
├────────────────┼─────────────────────────────────────────────────────────────┤
│ Acceleration   │ How fast they start from rest. (Currently unused in base   │
│ (0.85 - 1.15)  │ simulation but available for future features)              │
├────────────────┼─────────────────────────────────────────────────────────────┤
│ Endurance      │ How well they maintain speed over multiple laps.           │
│ (0.85 - 1.15)  │ High endurance = marathon runner. Low = sprinter who fades.│
└────────────────┴─────────────────────────────────────────────────────────────┘

Example Driver Archetypes:
  - The Consistent Pro: High speed, high consistency, low luck
  - The Lucky Underdog: Low speed, low consistency, HIGH luck
  - The Sprinter: High speed, high acceleration, low endurance
  - The Marathon Runner: Medium speed, high consistency, HIGH endurance
  - The Wildcard: High speed, VERY low consistency (anything can happen!)

================================================================================
                         TRACK GENERATION
================================================================================

Tracks are randomly generated with unique properties:

TRACK STRUCTURE:
  - Length: 300-1000 units per lap
  - Laps: 10-20 laps (longer races for tire strategy)
  - Difficulty: 1-10, affects tire wear rate
  - Chaos Modifier: Multiplier for random events
  - Weather: Visual theme and potential effects
  - SVG Layout: Unique track shape rendered visually

TRACK THEMES (determine visual style):
  - Volcano, Mountain, Ocean, Desert, Forest, etc.
  - Each has unique background gradient and track colors
  - Weather tendencies tied to theme

================================================================================
                         CONFIGURABLE PARAMETERS
================================================================================

All of these can be adjusted in the race config:

RACE STRUCTURE:
  - Total Laps: Number of laps to complete (default: 10-20, randomized)
  - Lap Length: Distance units per lap (default: 300-1000)
  - Tick Interval: Milliseconds between updates (default: 100ms)
  - Mandatory Pit Stops: Required pit stops (default: 2)

SPEED SETTINGS:
  - Base Speed Min: Slowest possible speed per tick (default: 5)
  - Base Speed Max: Fastest possible speed per tick (default: 20)

RANDOMNESS & CHAOS:
  - Chaos Level: How extreme random events are (0-1, default: 0.3)
  - Enable Random Events: Toggle events on/off (default: on)
  - Random Event Chance: Probability per tick (default: 5%)

STAT WEIGHTS:
  - Consistency Weight: How much consistency matters (default: 0.5)
  - Luck Weight: How much luck affects boost magnitude (default: 0.3)
  - Endurance Decay: Speed penalty per lap (default: 0.1)

TIRE/PIT/CRASH:
  - Tire Wear Rate: Base wear per tick (default: 0.02)
  - Pit Stop Duration: Ticks in pit (default: 40)
  - Base Crash Chance: Crash probability when close (default: 0.0008)
  - Enable Crashes: Toggle crash system (default: on)
  - Enable Tire Wear: Toggle tire wear system (default: on)

================================================================================
                            DEVELOPMENT TIPS
================================================================================

For Developers:
  - npm run dev - Start development server with hot reload
  - npm run build - Build for production
  - npm run preview - Preview production build

When tuning the simulation:
  1. Watch the race feed for unusual patterns
  2. Check the Analytics tab for factor breakdowns
  3. Look at tire degradation bars to see strategy impact
  4. Adjust compound properties in RaceEngine.ts TIRE_COMPOUNDS
  5. Reset and run again to compare

Key places to modify behavior:
  - TIRE_COMPOUNDS: Compound speed, wear rate, cliff severity, blowout risk
  - DEFAULT_CONFIG: Race length, crash chance, tire wear rate
  - calculateSpeed(): Luck proc chance, chaos effects
  - getTireSpeedModifier(): Degradation curve, cliff behavior
  - checkTireBlowout(): Blowout probability scaling
