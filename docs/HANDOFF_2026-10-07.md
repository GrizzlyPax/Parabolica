## TL;DR

- **The sim was rebuilt into something trustworthy.** Grid, qualifying, overtaking, a real pit strategy with a two-stop/three-compound rule, rarity-rolled tags that are earned and spread during a season. Every number has a lab that measures it.
- **Leagues are online.** A Cloudflare Worker at `playparabolica.com/api` holds each published league's facts. Every device replays the same deterministic engine, so phone and laptop show the same race at the same lap.
- **Fantasy teams are the first game layer.** Players snake-draft 3 drivers each and score their race points. Pax ran a full 16-race season with it on Oct 6 and liked it.
- **Race Control is the lab.** Tag calibration, physics calibration, presets you can race under, and a notebook that can send runs to a repo ledger.
- **Story is in a separate workstream** with its own agent. Code agents don't write story content.
- **Gods are parked.** The data stays; the UI no longer asks for one.

## 1. How the pieces fit (read before touching anything)

**Determinism is the foundation.** Everything that touches a race uses seeded RNG (`src/engine/rng.ts`: `mulberry32`, `deriveSeed`). Same seed + same inputs → identical race on every machine. Three tests pin this and must never be "fixed" by loosening them:
- `src/RaceEngine.test.ts` → **golden fingerprint**. Any change to physics, content pools or RNG order changes it. If the change is intended: bump `package.json` version, then `GOLDEN_UPDATE=1 npx vitest run -t fingerprint`, and say so in the PR.
- `src/league/replay.test.ts` → a season settled in one call equals one settled race by race.
- `src/league/remote.test.ts` → a league rebuilt from its server facts settles to identical results.

**Facts, not state.** A league is `(leagueSeed, setup, interventionLog)` plus the wall clock. Roster, tags, results and standings are all derived (`createLeague`, `rosterStateAt`, `settleLeague`). Anything new that must survive or be shared (fantasy teams, decrees, presets) goes into those facts, never into a derived snapshot. Fantasy lives in `LeagueSetupConfig.fantasy` for exactly this reason.

**One way to build a race.** Live broadcast, wall-clock settle and the lab all go through `createLeague` + `prepareScheduledRace` (`src/league/settle.ts`). The lab wraps this in `src/racecontrol/runner.ts`. Never set up an engine by hand somewhere new; that's how the old Sim Lab drifted from the real game.

**Tuning is data.** Physics knobs: `SimVariables` / `CANON_VARIABLES` in `src/simlab/types.ts` (every knob is listed with a meaning in `src/racecontrol/knobs.ts`). Rules: cards in `src/data/cards.ts` patch a `Ruleset` (`src/rules/ruleset.ts`). Content: `src/data/*`, `src/generators/*`.

**Content is gated by tests.** `src/data/worldDeck.test.ts` checks every tag, team, track, card and pool. It fails when:
- `docs/GLOSSARY.md` is stale (run `npm run glossary`);
- a genesis tag is missing from `src/data/tagCalibration.json`, changed since it was measured, or out of band (run `npm run calibrate`, ~15 min).

## 2. What shipped, by area

### The sim (#246 mechanics audit, #249 pit rule) — Oct 5–6
Audit doc: project note *mechanics-audit*; findings and each pass logged on [#246](https://github.com/GrizzlyPax/Parabolica/issues/246).
- **Pass 1 — tyres and pits.** Tyre life in laps (soft 5 / medium 7 / hard 9), a cliff that hurts, cheap stops (~¼ lap). Default rule: **at least 2 stops and all 3 compounds**, enforced at the flag with a time penalty (red `!` in the tower). Card *No Pit Rules* turns it off. `shouldDriverPit` has five reasons (cliff, ahead of the cliff, safety car, the rule, stay), shown as "Boxes — <reason>".
- **Pass 2 — qualifying and grid.** `runQualifying()` on tick 1, staggered grid, `getGridOrder()`, GRID and ▲/▼ columns.
- **Pass 3 — overtaking.** Cars get held in dirty air; passes are rolled events weighted by pace, tyres, aggression, defender and track. No passing under the safety car. `overtake` / `battle` events, `getBattles()`, ⚔ and rings on the track map.
- **Result (no tags):** pace→finish 0.37→0.61, grid→finish 0.66, pole wins 26%, stops 3.0→2.2, DNF 23%→17.6%.
- Probes: `npx tsx scripts/mechanics-probe.mjs 200` (the canonical gates), `scripts/action-probe.mjs`.

### Tags — Oct 5–6
- **Multi-tag stacks** (#231): up to 4 tags per driver, from several sources.
- **Genesis roll** (Pax's design, `src/rules/genesis.ts`): 3 slots (driver; car per driver; team shared by teammates) → each slot hits **1 in 6** → rarity bucket **60/30/9/1** (common/uncommon/rare/legendary) → even pick inside the bucket. Always three RNG draws per slot so odds changes don't shift other streams. Tiers were dropped; rarity is the only grade.
- **Acquisition engine** (#232): tags earned, inflicted and expired by results (`src/data/acquisitions.ts`); in-race tags picked up mid-race (`src/data/inRace.ts`, damage is a tag).
- **Action hooks** (#233): tags that spread, pass grudges, upgrade or wear off after a race (`afterRace` on the tag; `src/league/actions.ts`).
- **Legibility** (#243): tag cards, effect stack and history in the focused row, one TAGS column, rarity colours on chips.

### Rules of the run — Oct 5
- **Ruleset + cards** (#241): 11 cards patch tags, weather, physics. **Run Setup** page before a Quick Race: seed, track, cards, "rules underneath", grid with tag slots.

## 3. Traps we hit (save yourself the hour)

- **GitHub:** GraphQL is blocked in Claude sessions; use `gh api` REST. Creating a PR: `gh api repos/GrizzlyPax/Parabolica/pulls --input pr.json`. Merging: `gh api -X PUT .../pulls/N/merge -f merge_method=squash`. **Workflow dispatch is not permitted** from a session (403); to trigger `deploy-api`, push a change under `server/`.
- **Commit messages with quotes or arrows** break `git commit -m`; write the message to a file and use `git commit -F`.
- **Stray files:** `git add -A` once committed a Playwright script (`rc-dbg.mjs`, now gitignored as `rc-*.mjs`) and once committed `server/.wrangler/` (now gitignored). Check `git status` before committing.
- **Playwright** must run from the repo root (it imports from `node_modules`). Use `executablePath: '/opt/pw-browsers/chromium'`. Off-screen menu items: click with `el.evaluate(el => el.click())`.
- **The preview artifact** (claude.ai artifact `TKD2w88SkEdAA7eWgszpoA`, currently v46) blocks Web Workers and needs relative asset paths: copy `dist/*`, rewrite `"/assets/` → `"./assets/` in `index.html` and `index-*.js`, publish with a `files` map and `null` for the previous asset hashes. Hub's file says to republish after each merge.
- **CSS pruning:** a regex cleanup once deleted a whole block of Race Control styles (#268). Prefer exact-match edits that assert the match count.
- **Searching for colour on text:** look for `color:` and `fill:` in style objects, `fill=` on `<text>`, and `var(--team-color)` in CSS — all four forms exist.
- **Settle tests need real time:** a race broadcast takes minutes of wall clock; use `now` in the hours, not seconds, or nothing settles.
- **Safety car events are logged twice** by the engine; the probes and lab halve the count. Don't "fix" one side without the other.
