# Parabolica Race Engine

Formula 1 race simulation, building toward Commissioner Mode (wall-clock roguelite leagues).
Player betting was retired in June 2026 (git history has it); odds math survives in betting/utils
for the future NPC-crowd system (BetLab was removed Oct 2026; git history has it).

## Project Location
`/Users/pax/parabolica`

## Structure
- `src/` - All source code
  - `App.tsx` - Screen router: main menu, quick race, founding, league, compendium
  - `WatchMode.tsx` - Live race screen (track/detail views, finish modal)
  - `racecontrol/` - Race Control, the lab (unlocked from the menu): `runner.ts` is the ONE way a lab race is built (createLeague + prepareScheduledRace = live parity, fully seeded); `calibrate.ts` measures every genesis tag solo; `physics.ts` measures what the rules produce (mechanics-probe metrics); `knobs.ts` is the simVars registry; `labRunner.ts` runs jobs in a worker or on the main thread; `notebook.ts` keeps presets + runs in localStorage and sends batches to the shared ledger (`public/ledger/*`, fed by `ledger` issues via `.github/workflows/ledger.yml` + `scripts/ledger-ingest.mjs`) (Quick Race → Run Setup → Lab preset races under one via `applyLabPreset`); `RaceControl.tsx` hosts Tag calibration, Physics calibration, Notebook, Method
  - `simlab/types.ts` - `SimVariables` + `CANON_VARIABLES` (the engine's tuning surface; the old Sim Lab UI was folded into Race Control → Physics)
  - `data/tagCalibration.json` - GENERATED by `npm run calibrate`; a deck test fails when a genesis tag is missing, changed since measured, or out of band
  - `betting/utils.ts` - Pure odds/rating utilities (kept for NPC crowds later)
  - `feed/commentary.ts` - Race feed persona/commentary engine
  - `RaceEngine.ts` - Core race simulation engine (seedable: setSeed / runHeadless(seed))
  - `engine/rng.ts` - Seeded RNG (mulberry32, deriveSeed, shuffle) — determinism foundation
  - `storage/persistence.ts` - Versioned localStorage league save
  - `league/` - Commissioner Mode: seed → universe, wall-clock settle loop, interventions
    - `gods.ts` - Appetite gods (placeholder identities; evaluators are PR 5)
    - `ui/` - FoundingScreen, LeagueScreen (check-in reel, countdown, standings, chronicle)
    - `devConsole.ts` - window.league console (dev builds only)
- `dist/` - Production build output
- `public/` - Static assets

## Commands
- `npm run dev` - Start dev server (localhost:5173)
- `npm run build` - Production build
- `npm test` - Run vitest suite (engine determinism, league invariants, persistence)
- `npm run glossary` - Regenerate docs/GLOSSARY.md from the data modules (a test fails when it is stale)
- `npm run calibrate` - Re-measure every genesis tag → src/data/tagCalibration.json (~15 min; `-- 50 <tagId>` for a quick unwritten read)
- `npm run lab -- <seed> <races> all [cards…]` - Replay a Race Control batch in the terminal and print its fingerprint
- `gh issue list` - View GitHub issues
- `gh issue view <number>` - View specific issue
